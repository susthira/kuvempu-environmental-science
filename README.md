# Kuvempu University Environmental Science landing page

This folder is ready for GitHub Pages.

## Upload to GitHub
1. Create a new GitHub repository (for example, `environmental-science-admissions`).
2. Upload everything in this folder to the repository root.
3. Add your three approved images to `assets/images/` using these exact filenames:
   - `photo-1.jpg` — Western Ghats hero landscape; 1920 × 1080 px
   - `photo-2.jpg` — student field research; 1600 × 1200 px
   - `photo-3.jpg` — instruments / tools; 1600 × 1200 px
4. In the repository, go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then save.

GitHub will publish the site at the Pages address it displays.

## Before going live
- Replace the two `href="#"` links in `index.html` with the official admissions and enquiry URLs.
- Confirm all programme, eligibility, fee, intake, deadline and collaboration wording.
- Use only University-owned or appropriately licensed photographs.
